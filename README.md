# MTG Commander Hub V0.7

## Fullscreen Table Mode
- Die normale Wizards/Coach-Oberfläche verschwindet während einer Partie vollständig.
- 2–6 Spieler werden dynamisch auf dem gesamten Display angeordnet.
- Scryfall Commander-Artwork wird automatisch als Hintergrund des jeweiligen Spielerfelds verwendet.
- riesige Life-Anzeige
- komplette linke Hälfte eines Spielerfelds = -1 Leben
- komplette rechte Hälfte = +1 Leben
- Gift, Commander Damage und Commander Tax als kompakte Quick Counter
- Commander Damage öffnet eine übersichtliche Gegner-Auswahl
- Spieler-Menü für ±5 Leben, Commander Damage und Eliminierung
- zentrale schwebende HUD-Steuerung für Zug, Timer, Undo und Partie-Menü
- Event Log, Undo, Timer, Eliminierungen und Match-Speicherung aus V0.6 bleiben erhalten
- responsive Layouts für 2 bis 6 Spieler

Das normale App-Dashboard bleibt im bisherigen MTG-Coach/Wizards-Stil.
